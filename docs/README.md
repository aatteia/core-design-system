# Core documentation

> **Core is a foundation.** It is not a client product. It is not in production use.
> The live showcase is a demonstration of the kernel, not a shipped app.

Start here, then pick a path. The short product pitch is in the [root README](../README.md).

Canonical source is `tokens.css` and `components.css`. Docs must match those files.
